# DevOps Project

## Prérequis
- Docker
- Docker Compose
- Git

## Installation
git clone https://github.com/Hichemch-stack/devops-project.git
cd devops-project
docker-compose up -d

## Accès
Frontend: http://localhost:4200
Backend: http://localhost:8081/api/users
Jenkins: http://localhost:8080
SonarQube: http://localhost:9000
Nexus: http://localhost:8082
